📝 Important Notes:
  • Midnight Reset: The draw MUST reset to #1 at exactly 00:00:00 (midnight) every day. This is critical for daily operations.
  • Draw Number Verification: Always verify the draw number is correct before starting operations each day.
  • Backup Before Reset: Always create a database backup before the midnight reset occurs.
  • Synchronization: After any reset or manual change, verify all systems (MySQL, Firebase, TV Display) are synchronized.
  • Emergency Reset: If draw numbers get out of sync, use complete_system_reset.php or reset_database.php to reset manually.
  • Monitoring: Use draw_number_monitor.html to continuously monitor draw numbers throughout the day.
  • Firebase Sync: If Firebase and MySQL get out of sync, check the sync status and manually sync if needed.
