Login Troubleshooting Guide

The Issue: AJAX Error with HTML Response

You're seeing an error like this:

AJAX Error: parsererror SyntaxError: Unexpected token '<', "

This happens because the AJAX request is expecting JSON data, but it's receiving HTML instead. This is a common issue when PHP scripts return HTML instead of the expected JSON format.

Solution 1: Use the Dedicated AJAX Login Endpoint

We've created a dedicated AJAX endpoint that always returns JSON:

Additional Troubleshooting

If you're still having issues:

  • Make sure XAMPP is running with MySQL service active
  • Check that the database connection parameters in the PHP files are correct
  • Try clearing your browser cache or using a different browser
  • Check the PHP error logs in XAMPP for any additional errors
