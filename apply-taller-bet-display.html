Taller Bet Display Panel

This page provides multiple ways to make your bet display panel taller, reaching down to the Custom Amount button.

How to use this tool:

  1. Apply directly: Click the "Apply Height Change Now" button to immediately make the bet display taller on the current page.
  2. Permanent solution: Click "Copy CSS for Permanent Solution" to copy CSS code that you can add to your style.css file for a permanent change.
/* * Custom Bet Display CSS * This CSS applies a taller height to the bet display container, * extending it down to the Custom Amount button. */ .bet-display-container { height: 750px !important; max-height: none !important; } .bet-display-body { max-height: calc(750px - 90px) !important; /* Accounting for header and stake control height */ } .bet-display-list { max-height: 850px !important; }
